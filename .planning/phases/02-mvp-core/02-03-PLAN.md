       - `validateImageBuffer(buffer, mimeType)`: checks MIME in allowed list and verifies magic bytes (JPEG: FF D8 FF, PNG: 89 50 4E 47, WebP: RIFF...WEBP).
       - Enforces max file size $\le 10$ MB (`MAX_IMAGE_FILE_SIZE_BYTES`).

       - Checks project status; if `ARCHIVED`, immediately returns 409 Conflict.
       - Enforces user rate limit (`RATE_LIMIT_CONFIGS.IMAGE_UPLOAD` / 20 uploads/day); returns 429 with `Retry-After` if exceeded.

       - Enqueues job to BullMQ `image-analysis-queue` (updates state to `QUEUED`). Note: No visualization queues are created or referenced.
    3. Implement `DELETE /api/v1/projects/[id]/images/[imageId]`:
       - Soft-deletes `ProjectImage` by updating `processingState = DELETED`, excluding from subsequent analysis and recommendation runs.
    4. Implement `src/components/images/ImageUploadZone.tsx`:
       - Drag-and-drop zone, file size check, upload progress indicator, preview thumbnails.
    5. Write unit tests in `tests/images/upload.test.ts`:
       - Valid upload returns 201 and enqueues job.
       - Invalid MIME or spoofed magic bytes returns 400.
       - Oversized file (> 10MB) returns 400.
       - Upload to archived project returns 409.
       - Rate limit exceeded returns 429.
  </action>

<task type="auto">
  <name>Task 2: Asynchronous BullMQ Gemini Vision Analysis Worker (Tasks 1.6.1–1.6.7)</name>
  <files>src/lib/vision/gemini-client.ts, src/workers/analysis-worker.ts, tests/vision/gemini-analysis.test.ts</files>
  <read_first>.kiro/specs/paint-platform/design.md#4-database-schema, .kiro/specs/paint-platform/design.md#10-ai-image-analysis, .kiro/specs/paint-platform/tasks.md#16-ai-image-analysis</read_first>
  <action>
    1. Implement `src/lib/vision/gemini-client.ts`:
       - Initializes Gemini Vision client using `env.GEMINI_API_KEY` and `env.IMAGE_ANALYSIS_MODEL`.
       - Crafts structured visual analysis prompt requesting JSON schema output:
         `spaceType`, `isInterior`, `facadeType`, `floorCount`, `architecturalStyle`, `visibleSurfaces`, `naturalLightQuality`, `paintableRegions`, and confidence scores.
       - Implements error classifier:
         - Transient/Quota/Timeout $\rightarrow$ retryable error.
         - Safety Refusal (`finishReason == 'SAFETY'`) $\rightarrow$ non-retryable safety refusal with detailed reason.
    2. Enhance `src/workers/analysis-worker.ts`:
       - Dequeues job from `image-analysis-queue`.
       - Transitions `ProjectImage.processingState` to `PROCESSING`.
       - Generates temporary read SAS token to fetch image bytes from Azure Blob.
       - Invokes `GeminiAnalysisClient.analyzeImage`.
       - On success:
         - Creates `ImageAnalysisResult` (strict 1:1 non-null foreign key relation `projectImageId` to `ProjectImage`) storing inferred properties, JSON surfaces, and confidence scores.
         - Sets `analysisState = AI_INFERRED`.
         - Updates `ProjectImage.processingState` to `COMPLETED`.
       - On retryable failure:
         - Increments `retryCount`. If `retryCount < 3`, sets state `RETRYING` and throws for BullMQ exponential backoff.
         - If exhausted, sets state to `FAILED`.
       - On safety refusal:
         - Sets `ProjectImage.processingState = FAILED` immediately (no retry).
         - Records `ImageAnalysisResult.safetyRefusalReason`.
         - Writes `SAFETY_REFUSAL` event to `AuditLog`.
    3. Write test suite in `tests/vision/gemini-analysis.test.ts`:
       - Valid response creates ImageAnalysisResult with AI_INFERRED state and non-null unique projectImageId.
       - Safety refusal sets state FAILED without retry and writes AuditLog.
       - State transition monotonicity test: FAILED never transitions back to PROCESSING.
       - Invariant test: Zero reference to visualization queue or generative preview jobs.
  </action>
  <verify>Run `npx vitest run tests/vision` to verify worker state machine transitions and Gemini response handling.</verify>
  <acceptance_criteria>
    - Gemini client extracts structured JSON schema with confidence scores
    - Safety refusal goes directly to FAILED and writes AuditLog
    - Successful analysis creates ImageAnalysisResult linked 1:1 (non-null projectImageId) to ProjectImage
    - All tests in tests/vision pass
  </acceptance_criteria>
  <done>Gemini Vision analysis worker, relational integrity, and state machine implemented.</done>
</task>
