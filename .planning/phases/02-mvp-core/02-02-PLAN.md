  <name>Task 2: Open-Meteo Climate Service & Regional Fallback Engine (Tasks 1.4.1–1.4.7)</name>
  <files>src/lib/climate/open-meteo.ts, src/lib/climate/regional-fallback.ts, src/lib/climate/service.ts, src/data/regional-climate.json, src/app/api/v1/projects/[id]/climate/route.ts, src/components/climate/ClimateDisplayCard.tsx, tests/climate/climate.test.ts</files>
  <read_first>.kiro/specs/paint-platform/design.md#11-climate-profile-retrieval, .kiro/specs/paint-platform/tasks.md#14-climate-profile-retrieval</read_first>
  <action>
    1. Create bundled regional climate fallback dataset `src/data/regional-climate.json` covering major Indian climatic zones (Hot & Dry, Warm & Humid, Composite, Temperate, Cold) with 12 monthly observations each.
    2. Implement `src/lib/climate/open-meteo.ts`:
       - `OpenMeteoClient`: fetches monthly aggregate temperatures, relative humidity, precipitation, UV, and wind speeds for lat/long.
    3. Implement `src/lib/climate/regional-fallback.ts`:
       - `RegionalAggregateClient`: matches coordinates against regional bounding boxes; returns fallback monthly aggregates.
    4. Implement `src/lib/climate/service.ts`:
       - `ClimateService`: retries Open-Meteo up to 3 times with exponential backoff.
       - If primary exhausts, invokes `RegionalAggregateClient`, assigns `provenance = DERIVED`, and persists DataSource reference.
       - Persists `ClimateProfile` and exactly 12 `ClimateObservation` records in Azure SQL.
       - If neither source is available, throws `ClimateUnavailableException` and disallows recommendations.
    5. Implement `GET /api/v1/projects/[id]/climate`:
       - Returns `ClimateProfile` with observations. If `provenance == 'DERIVED'`, attaches `climateDataNote: "Regional average climate data was used. Local conditions may vary."`.
    6. Implement `src/components/climate/ClimateDisplayCard.tsx`:
       - Visual monthly bar charts and annual metrics summary with prominent DERIVED notice when applicable.
    7. Write test suite in `tests/climate/climate.test.ts`:
       - Test primary VERIFIED path.
       - Test fallback DERIVED path with notice assertion.
       - Property test: returns exactly 12 monthly observations for valid coordinates.
  </action>
  <verify>Run `npx vitest run tests/climate` to confirm 12-month retrieval, fallback triggering, and exception handling.</verify>
  <acceptance_criteria>
    - ClimateProfile records exactly 12 ClimateObservation rows
    - Fallback path sets provenance=DERIVED and includes climateDataNote
    - Failure to retrieve climate data prevents recommendation runs
    - All tests in tests/climate pass
  </acceptance_criteria>
  <done>Open-Meteo climate profiling engine and regional fallback completed.</done>
