<task type="auto">
  <name>Task 2: Project Management Service & REST Endpoints (Tasks 1.2.1–1.2.7)</name>
  <files>src/lib/projects/service.ts, src/app/api/v1/projects/route.ts, src/app/api/v1/projects/archived/route.ts, src/app/api/v1/projects/[id]/route.ts, src/app/api/v1/projects/[id]/archive/route.ts, src/app/api/v1/projects/[id]/unarchive/route.ts</files>
  <read_first>.kiro/specs/paint-platform/design.md#4-database-schema, .kiro/specs/paint-platform/design.md#6-api-design, .kiro/specs/paint-platform/design.md#23-project-archival-and-lifecycle, .kiro/specs/paint-platform/tasks.md#12-project-management</read_first>
  <action>
    1. Implement `src/lib/projects/service.ts`:
       - `createProject(userId, { name, description, applicationScope })`: Creates Project with `status: ACTIVE`. Accepts `applicationScope` (`INTERIOR`, `EXTERIOR`, `BOTH`).
       - `listActiveProjects(userId)`: Returns active projects ordered by `updatedAt DESC`.
       - `listArchivedProjects(userId)`: Returns archived projects.
       - `getProjectById(userId, projectId)`: Enforces ownership; returns 403 Forbidden and writes `SECURITY_VIOLATION` to `AuditLog` if owned by another user.
       - `updateProject(userId, projectId, data)`: Rejects updates to `ARCHIVED` projects with 409 Conflict.
       - `archiveProject(userId, projectId)`: Sets `status: ARCHIVED`, `archivedAt: new Date()`.
       - `unarchiveProject(userId, projectId)`: Clears `archivedAt`, sets `status: ACTIVE`.
    2. Implement API Routes:
       - `POST /api/v1/projects` (Task 1.2.1)
       - `GET /api/v1/projects` (Task 1.2.2)
       - `GET /api/v1/projects/archived` (Task 1.2.3)
       - `GET /api/v1/projects/[id]` & `PATCH /api/v1/projects/[id]` (Tasks 1.2.6, 1.2.7)
       - `POST /api/v1/projects/[id]/archive` (Task 1.2.4)
       - `POST /api/v1/projects/[id]/unarchive` (Task 1.2.5)
  </action>
  <verify>Run unit tests asserting 200/201 on valid calls, 403 on unauthorized access, and 409 on modifying archived projects.</verify>
  <acceptance_criteria>
    - All 6 endpoints implemented with strong Zod input validation
    - Archive and unarchive use `POST` method per Design §23.1
    - Archived project modification rejects with HTTP 409
    - Unauthorized access returns HTTP 403 and records AuditLog
  </acceptance_criteria>
  <done>Project management service and REST endpoints fully operational.</done>
