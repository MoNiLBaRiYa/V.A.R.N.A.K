  <action>
    1. Implement `src/lib/recommendations/factors.ts`:
       - Define the exactly nine factor scoring functions returning 0.0 to 1.0:
         1. `CLIMATE_SUITABILITY`: `calculateClimateSuitability(shade, climate)`
         2. `INTERIOR_EXTERIOR_COMPATIBILITY`: `calculateScopeCompatibility(product, scope)`
         3. `SURFACE_COMPATIBILITY`: `calculateSurfaceCompatibility(product, visibleSurfaces)`
         4. `PRODUCT_SUITABILITY`: `calculateProductSuitability(product, analysis)`
         5. `ARCHITECTURAL_CHARACTERISTICS`: `calculateArchitecturalCharacteristics(shade, style)`
         6. `ROOM_TYPE`: `calculateRoomTypeSuitability(product, roomType)`
         7. `NATURAL_LIGHT`: `calculateNaturalLightSuitability(shade, naturalLight)`
         8. `COLOUR_FAMILY_COMPATIBILITY`: `calculateColourFamilyCompatibility(shade, context)` (unambiguously in MVP)
         9. `USER_PREFERENCES`: `calculateUserPreferences(shade, preferences)` (in MVP, returns neutral baseline 0.5 when preferences are unconfigured; zero preference UI/questionnaires pulled into Phase 2).
    2. Implement `src/lib/recommendations/harmony.ts`:
       - `applyPaletteHarmony(rankedCandidates)`:
         - Deterministic post-scoring rule applied after composite scoring.
         - Checks if $\ge 4$ of top 5 share the same `colourFamily`.
         - If concentrated, scans positions 6–15 (inclusive) for an alternative family passing mandatory filters.
         - If found, removes the lowest-ranked candidate belonging to the concentrated family (at rank 5), inserts the alternative candidate, re-ranks top 5 in `compositeScore DESC` order.
         - Flags `isHarmonyReplacement: true` and `replacedCandidateId`.
         - Important: Palette Harmony does NOT modify factor scores or composite scores.
    3. Implement `src/lib/recommendations/relaxation.ts`:
       - Sequential relaxation steps if fewer than 5 candidates remain:
         (1) `COLOUR_FAMILY_COMPATIBILITY` -> (2) `NATURAL_LIGHT` -> (3) `ROOM_TYPE` -> (4) `ARCHITECTURAL_CHARACTERISTICS`.
       - Halts at the first step yielding $\ge 5$ eligible candidates and captures step history in `relaxationApplied`.
    4. Implement `src/lib/recommendations/explanation.ts`:
       - Formulates deterministic natural language explanation describing key contributing factors (climate resilience, surface adherence, style synergy).
    5. Implement `src/lib/recommendations/engine.ts`:
       - Executes strict 9-step sequence:
         Step 1: Load active PaintShades for Asian Paints (`provenance == VERIFIED`, `isActive == true`).
         Step 2: Apply mandatory compatibility filters (`provenance == VERIFIED`, `isActive == true`, application scope compatibility, surface intersection).
         Step 3: Compute all 9 factor scores for each eligible candidate.
         Step 4: Compute composite score: $\sum (factorScore_i \times weight_i)$ using active `ScoringWeightVersion` (`v1.0.0`).
         Step 5: Sort candidates deterministically (`compositeScore DESC`, `shadeId ASC`).
         Step 6: Apply Palette Harmony post-scoring diversity rule.
         Step 7: Apply Filter Relaxation sequence if fewer than 5 candidates remain after steps 2–6.
         Step 8: Persist top 5 `Recommendation` and 45 `RecommendationFactor` (9 per recommendation) records.
         Step 9: Persist `RecommendationRun` record with `scoringWeightsVersionId`, snapshot tag `scoringWeightsVersion`, and `relaxationApplied`.
       - For `ApplicationScope.BOTH`: the MVP recommendation engine generates exactly 5 recommendations in a single ranked list per authoritative specifications. Separate dual-list generation for `BOTH` is strictly deferred to Phase 3 (Wave 2).
    6. Implement `POST /api/v1/projects/[id]/recommendations`:
       - Enforces daily rate limit (10 runs/day; returns 429 Retry-After).
       - Requires active project (rejects archived with 409) and valid ClimateProfile (rejects with 422 if climate data missing).
       - Invokes engine and returns top 5 recommendations.
    7. Write tests in `tests/recommendations/`:
       - Scoring tests: verify score range 0.0–1.0 across all 9 factors and weight summation to 1.0.
       - Harmony test: verify position 5 replacement upon 4-shade concentration; verify unchanged when diversity present; verify factor/composite scores are preserved.
       - Relaxation test: verify exact design relaxation order.
       - ApplicationScope test: verify recommendation engine returns single 5-shade list for BOTH; assert no test expects dual lists in MVP.
       - Determinism test: identical inputs produce identical output.
  </action>

    - Sequential relaxation stops at first step with >= 5 candidates
