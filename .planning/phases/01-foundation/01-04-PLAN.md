  <read_first>.kiro/specs/paint-platform/design.md#3-authentication-architecture, .kiro/specs/paint-platform/tasks.md#05-authentication-setup</read_first>
  <action>
    1. Implement Auth.js session protection in `src/middleware/auth.ts` (Task 0.5.3):
       - Intercept all requests matching `/api/v1/*` (except public health checks).
       - Validate active session token. If missing or expired, return HTTP 401 Unauthorized with JSON error.
    2. Implement post-login callback handler in `src/lib/auth/callbacks.ts` (Task 0.5.4):
       - On successful Entra callback, upsert `User` record in Azure SQL database via Prisma:
         `internalUserId` (UUID), `externalSubjectId` (Entra `sub`), `email`, `role = USER`, `lastLoginAt = now()`.
       - Write tamper-evident `AuditLog` entry for authentication events:
         - `REGISTRATION` on initial user creation
         - `LOGIN` on successful session establishment
         - `EMAIL_VERIFIED` when confirmed by provider
       - Pass internal `userId` and `role` into application session token for downstream authorization.
  </action>
  <verify>Run unit tests in `tests/auth/auth.test.ts` verifying middleware 401 behavior and user upsert/audit logging.</verify>
  <acceptance_criteria>
    - `src/middleware/auth.ts` rejects unauthenticated `/api/v1/*` requests with HTTP 401
    - `src/lib/auth/callbacks.ts` upserts `User` record with external subject ID and logs audit event
    - Passwords, hashes, and TOTP secrets are never processed or stored
  </acceptance_criteria>
  <done>Session protection middleware and user upsert callback handler implemented.</done>
</task>
